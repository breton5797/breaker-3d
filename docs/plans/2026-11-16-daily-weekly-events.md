# 매일·매주 이벤트 (재방문율 고도화)

2026-11-16 대표님 요청: "매일, 매주 이벤트를 통해 유저들의 재방문율을 높이는 고도화 작업". 같은 날 기획 승인(일일 미션 3개 + 주간 챌린지 3단계 + 주간 스탬프).

## 구성

| 항목 | 내용 | 보상 (확정형) |
|---|---|---|
| 일일 미션 | 매일 자정(기기 날짜) 교체. 쉬움/보통/도전 3개, 서로 다른 지표. 날짜로만 정해짐 (모두 같은 미션). 파이프 미션은 10스테이지가 열린 뒤에만. | 50 / 80 / 120 골드 |
| 전부 완료 보너스 | 3개를 모두 받으면 | 150 골드 (하루 최대 400) |
| 주간 챌린지 | 매주 월요일 교체. 지표 4종(클리어·과일·보스·코인)을 주마다 돌아가며, 누적 3단계 | 200 / 400 / 800 골드 |
| 주간 스탬프 | 3단계를 모두 받으면 그 주의 스탬프 1개 (영구 보관) | 수집품 |

지표: 과일 받기, 스테이지 클리어, 보스 격파, 코인 모으기, 스킬 사용, 파이프 끝 통과, 별 3개 클리어. 판이 끝날 때(클리어·게임오버) 한 번에 기록, 보상은 이벤트 창에서 직접 탭해 받음.

## 옥탈리시스 매핑

- CD2 진보와 성취: 진행 막대, 단계, 전부 완료 보너스
- CD4 소유권: 주간 스탬프 수집
- CD7 예측 불가능성(약하게): 매일 바뀌는 미션 조합 (보상 자체는 고정)
- 블랙햇(CD6 조급함, CD8 손실) 사용 안 함: 카운트다운 없음, 놓친 날 처벌·연속 끊김 없음
