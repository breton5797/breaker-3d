# 1라운드 — 검증가 (brainstorm-critic)

## 코드로 확인한 전제 (화면 px는 framing 파라미터로 낸 추정치, 실측 필요)
- 세로 390px 폭: 1칸 ≈ 4.0px, 1행 ≈ 3.8px. 패들 윗면 → 판정선(y>9) ≈ **9~10px** — 손끝 접촉면(40px+)보다 훨씬 작다. 아래쪽은 보드 밖(스킬 영역 140px + 안전영역)까지 띠로 판정되어 실질 띠 = 화면 하단 약 165~200px + 패들 위 10px.
- 판정선이 패들 바로 위라 "패들 위에 올렸다"고 생각해도 10px만 위로 찍히면 조준 모드 → 대표님 불만의 직접 원인일 가능성(가설).
- 넓은 각도(75°+)는 판정선 위 3~5행(12~20px) 안에서 정해진다 → 띠 경계와 맞붙음.
- 마우스는 이미 호버 이동 + 클릭드래그 조준이라 문제없음. 키보드는 이동/발사 분리되어 있으나 각도 키 없음.
- 스킬 버튼(좌하단 약 74×142px)은 pointerdown만 전파 차단, 스킬은 click으로 실행(메테오 = 탭 즉시 코인 사용). 버튼에서 시작한 드래그가 패들을 움직일 수 있음 → 실기기 확인 필요.
