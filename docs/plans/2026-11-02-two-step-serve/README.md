# 2단계 서브 입력 브레인스토밍 (2026-11-02)

## 고민거리 (대표님)
> 첫 시작에서 핸드폰을 터치 및 드래그해서 바 위치를 옮기고, 그다음에 손을 떼었다가 누른 상태에서 다양한 방향을 조절해서 공이 뿌려지게끔 하고 싶다.

## 현재 문제 (코드 기준)
- 공 대기 중 누르면 조준 시작. 손가락이 패들 위 약 10px 판정선(`AIM_LIFT` 3행) 아래면 패들 이동, 위면 각도 조절 (`src/aimInput.js`).
- **떼면 무조건 발사** (`src/main.js` pointerup) → 바만 옮기려 해도 공이 나감.
- 마우스(호버 이동 + 클릭드래그 조준)와 키보드(←→ 이동, Space 발사)는 문제없음 → 터치 전용 문제.
