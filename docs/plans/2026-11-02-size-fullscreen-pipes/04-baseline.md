# 첫 과일 시간 기준선 (2026-11-02)

관(파이프) 시험의 비교 기준. `node scripts/first-fruit.mjs 1 59 9` 결과 그대로.

- 봇: autoplay.mjs와 같은 봇(가장 낮게 떨어지는 공·과일을 쫓음, 조준 오프셋). 사람보다 훨씬 약하고 공을 과일보다 먼저 쫓음 → **절대 난이도 지표가 아니라 관 있음/없음 비교용 고정 잣대**.
- 시드 9개, 180초(시뮬) 안에 과일을 못 받으면 no-fruit. entry = 서브의 공이 처음 박스에 들어간 시각(`w.entered`), fruit = 첫 과일을 받은 시각. 중앙값은 성공한 시드끼리만.
- 시드 간 편차가 매우 큼(같은 스테이지에서 5초~180초 이상). 관 시험 판정은 시드를 30개 이상으로 늘리고, 관 있음/없음을 같은 시드로 비교할 것.
