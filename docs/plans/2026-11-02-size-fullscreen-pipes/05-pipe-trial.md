# 관 시험 1차 (2026-11-02, 88 x 118 판 기준)

`node scripts/pipe-trial.mjs 60000 41` — 스테이지 41(숫자 1)의 바닥 구멍(x=44) 위에 폭 3칸 강철관을 깎고,
패들에서 알려진 히트 위치로 공을 6만 번 쏘아 관에 들어간 공의 결과를 셈. 게임에는 아직 아무것도 넣지 않음.

- through = 관 끝 칸에 닿음(그 너머가 벽화·과일), back = 구멍으로 되돌아 나옴, stuck = 관 안 10초 초과

- 관 모양: I = 위로 26칸 직선, L = 위로 14칸 후 오른쪽으로 16칸

## 다음 할 일
1. L관 갇힘 원인 분석 → 해결(예: 꺾임 모서리를 비스듬히 깎기, 관 안 최소 진행 속도). 해결 전에는 게임에 넣지 않음.
2. edge 표본을 늘려(가장자리 히트 위주로 서브) 프레임 차이 재측정.
3. I관은 긴장 효과가 없으므로 제외하거나 튜토리얼용으로만. Z/S·U는 L 통과 후 같은 방식으로 측정.
4. 관을 스테이지 생성에 붙인 시험판으로 첫 과일 시간(04-baseline 대비) 측정.

## 2차 (같은 날) — 갇힘 원인과 해결
- 원인: 관 폭은 3칸인데 바닥 구멍은 1칸. 내려오던 공이 대부분 구멍 옆 강철 바닥에 맞고 다시 올라가, 바닥·뚜껑·벽 사이의 주기 궤도에 걸려 두 출구(아래 1칸 구멍, 꺾임 입구 3칸)를 계속 비켜 감. 갇힌 공은 모두 꺾임 접합부(x≈44, y≈42~44)에서 정상 속도로 튀고 있었음 → 물리 버그가 아니라 형태 문제.
- 해결: 관 입구(바닥)를 관 폭(3칸) 전체로 엶 = 판정자 설계의 "관 입구는 더 크게"와 같음.
