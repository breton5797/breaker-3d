근거: 앱인토스 개발자센터·블로그·테크챗 검색(2026-11-23). 정책은 자주 바뀌므로 제출 전에 콘솔 안내를 다시 확인한다.

## 빌드

```
npm run app:toss        # vite build --mode toss && ait build  →  breaker-3d.ait (약 21MB, 한도 100MB)
```

- `apps-in-toss.config.ts`의 `appName`은 콘솔에 등록한 앱 이름과 같아야 한다 (지금은 `breaker-3d` 자리표시자).
- 보상형 광고 그룹 ID: 콘솔에서 받은 운영 ID를 빌드 환경변수 `VITE_TOSS_REWARDED`로 넣는다. 비우면 토스 테스트 ID(`ait-ad-test-rewarded-id`). 운영 ID로 테스트 금지(제재).
- 웹·Android·iOS 빌드는 그대로다. 토스 SDK는 `--mode toss` 빌드에서만 불린다.

## 토스 빌드에서 달라지는 점 (코드)

| 항목 | 내용 | 파일 |
| --- | --- | --- |
| 광고 | AdMob 직접 연동 금지 → 토스 광고 SDK(`GoogleAdMob.loadAppsInTossAdMob`/`showAppsInTossAdMob`) 보상형만. 보상은 `userEarnedReward`일 때만 | `src/monetize/tossAds.js`, `platform.js` |
| 상점 | 광고 제거 구매 없음(1차). 토스 인앱 결제는 2차 | `platform.js` |
| 뒤로가기 | 분할 선택 닫기 → 일시정지/재개 → 결과 화면은 타이틀로 → 하위 화면 닫기 → 타이틀에서는 미니앱 닫기(`closeView`) | `src/toss.js` |
| Safe Area | `SafeArea.get()` 값을 `--safe-top/--safe-bottom`으로 (CSS는 env() 대체값 유지) | `src/toss.js`, `style.css` |
| 외부 링크 | 사진 출처의 위키미디어 링크를 글자로만 표시 (외부 URL 열기 금지) | `src/ui.js` |
| 전체 화면 버튼·오프라인 캐시 | 숨김·미등록 (토스 게임은 원래 전체 화면, 파일은 번들에 포함) | `main.js`, `boot.js` |

## 대표님 수동 작업 (제출 전)

1. 앱인토스 콘솔 가입 (만 19세 이상, 본인 명의 토스앱·토스 비즈니스 회원) → 워크스페이스 생성 → 사업자 등록(미니멀코리아) → 앱 등록(카테고리: 게임, 세로 고정) → 앱 이름(appName) 알려주기.
2. 게임물 등급분류: 게임물관리위원회 신청 시 스토어명 "기타-앱인토스", 또는 이미 받은 자체등급분류를 콘솔에 등록(화면 이미지 2장). 등급은 브릿지 뷰(게임 접속 화면)에 표시된다.
3. 콘솔에서 보상형 광고 그룹 생성 → 그룹 ID 전달 (광고 수익은 사업자 등록·승인 필요, 누적 예상수익 5천 원까지 유예).
4. 샌드박스(토스 앱)에서 `.ait` 테스트 — QR로 대표님 휴대폰에서 실행해 확인.
5. 검수 요청: 공식 최대 3영업일, 첫 출시는 최대 7영업일. 제출 버튼은 대표님 승인 후.
