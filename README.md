# BREAKER 3D

공 하나가 3,000개가 되는 3D 벽돌깨기. 랜드마크 그림은 **강철 상자** 안에 있고, 아래·옆·위·모서리에 뚫린
**공 1개 크기의 작은 구멍**으로만 들어갈 수 있습니다. 공을 구멍에 넣으면 안에서 계속 벽돌을 깨고, 깨진 **과일 아이템 벽돌(🍒×2/🍓×3/🍊×5/🍎×7/🍉×9/🍍×10)**
에서 떨어지는 아이템을 패들로 받으면 공 개수가 그 배수만큼 늘어납니다. 연쇄 폭탄·레이저·화염공도 있습니다.
**무한 모드**: 단계 제한이 없고, 1단계는 누구나 깰 수 있게 쉬우며 단계마다 조금씩 어려워집니다. 맵은 고대 유적과 세계 명소 24종(피라미드·스톤헨지·에펠탑·숭례문·마추픽추 등)이고, 한 바퀴를 돌면 노을·밤 버전으로 다시 나옵니다. 상자 안에는 그 랜드마크의 실제 사진이 깔려 있습니다(출처: [CREDITS.md](CREDITS.md)). 구멍은 10단계까지 4개, 20단계까지 3개, 30단계까지 2개, 그 뒤로는 1개이고, 단계가 오를수록 들어가기 어려운 자리(모서리 → 바닥 → 천장·옆벽)로 옮겨 갑니다. 과일은 스테이지마다 8개 안팎이고, 대신 🪙 골드 벽돌에서 떨어지는 동전을 받으면 골드가 계속 쌓입니다.
기획은 [PLAN.md](PLAN.md).

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # 시뮬레이션 단위 테스트 (vitest)
npm run build    # dist/ 정적 빌드
node scripts/autoplay.mjs [seed] [stage,...]   # 봇으로 단계별 밸런스 측정
```

## 조작

| 입력 | 동작 |
|---|---|
| 마우스 / 터치 드래그, ← → / A D | 패들 이동 |
| 클릭 / 탭 / Space | 발사 |
| 1 / Q | 스킬: 전체 공 ×3 분열 |
| 2 / W | 스킬: 메테오 (관통 화염공 부채꼴) |
| P / Esc | 일시정지 |

## 구조

- `src/sim/` — 렌더와 무관한 순수 게임 로직 (테스트 대상)
- `src/render/` — Three.js 렌더링 (InstancedMesh, 블룸, 파편/충격파/레이저)
- `src/director.js` — 시뮬레이션 이벤트 → 연출·사운드·슬로모션
- `src/audio.js` — WebAudio 합성 사운드 (에셋 없음)
- `src/ui.js`, `src/storage.js` — HUD/메뉴, 진행도 저장(localStorage)
